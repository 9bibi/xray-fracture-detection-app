About This System

Deep Learning Model

ResNet50 pre-trained on ImageNet, fine-tuned on 36,808 MURA orthopedic X-rays using a two-phase transfer learning strategy.

Classification

Research classifier for abnormality/fracture suspicion. The interface uses a review zone to avoid overconfident borderline decisions.

Model Performance

Accuracy 81.4% · Precision 82.9% · Recall 77.4% · F1 80.1% · AUC-ROC 0.873 on the MURA validation set.

Explainability (Grad-CAM)

Gradient-weighted Class Activation Maps highlight regions the model focuses on — warm colors indicate fracture-relevant areas.

Dataset

MURA v1.1 (Stanford) — 7 body parts: Elbow, Finger, Forearm, Hand, Humerus, Shoulder, Wrist. 40,005 total images.
